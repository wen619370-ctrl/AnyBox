# AnyBox · 万用沙盒

**本地 AI 工具箱宿主程序** — 用自然语言描述需求，LLM 自动生成并执行 Python 脚本，即时呈现结果。

```
你说："帮我批量重命名这 50 张图片，按拍摄日期排序"
AnyBox 自动生成脚本 → 沙盒执行 → 完成！
```

---

## ✨ 功能特性

- 🧠 **对话式工具创建** — 像聊天一样描述需求，AI 自动生成工具代码
- 🔒 **本地执行** — 工具脚本在本地沙盒运行，数据不出本机
- 🎨 **动态 UI** — 工具界面由 AI 自动生成，无需手写前端
- 🗂️ **工具库** — 保存、管理、复用已创建的工具
- 🪟 **PySide6 桌面应用** — 现代化 Qt 界面，支持 Windows

---

## 🔧 内置环境能力

AnyBox 生成的脚本均运行在**宿主 Python 环境**中，基于 Python 标准库 + 少量运行时协议即可实现以下类型的工具：

### 文件处理
- 📄 批量文件重命名、格式转换（CSV ↔ Excel、文本编码转换等）
- 🗜️ 文件压缩 / 解压（ZIP、tar.gz）
- 📊 日志分析、CSV 数据筛选与统计
- 🔍 目录对比、重复文件查找、文件内容搜索替换

### 系统操作
- 🖥️ 调用外部程序（subprocess）进行自动化处理
- 📁 目录创建、文件移动 / 复制 / 归档整理
- 🔐 文件 hash 校验（MD5 / SHA256）

### 数据处理
- 📈 文本处理（正则匹配、按行过滤、合并拆分）
- 🏷️ JSON / YAML / INI 配置文件的读写与批量修改
- 📝 Markdown 文档生成、模板渲染

### AI 生成的 UI 控件
AnyBox 可自动调度以下控件来组装工具界面（无需手写前端）：

| 控件类型 | 说明 |
|---------|------|
| `text_input` | 单行文本输入（如文件名前缀、搜索关键词） |
| `folder_picker` | 文件夹选择器 |
| `file_picker` | 文件选择器（可限定类型，如 `*.jpg`） |
| `multi_folder_picker` | 多文件夹批量选择（支持拖拽） |
| `multi_file_picker` | 多文件批量选择（支持拖拽） |
| `dropdown` | 下拉选择（如选择编码格式、处理模式） |
| `checkbox` | 复选框（如是否递归处理子目录） |
| `label` | 纯文本标签（显示提示信息） |

> 💡 **提示**：AnyBox 已内置独立 Python 沙盒（`sandbox/python-embed/`，Python 3.12 + pip），生成的脚本均在沙盒中隔离运行，与宿主环境互不影响。如需第三方库，pip 将自动安装到沙盒中。

## 🚀 快速开始

### 1. 下载安装

从 [Releases](../../releases) 页面下载最新 `AnyBox.exe`，直接运行即可（无需安装 Python 环境）。

> ⚠️ **重要提醒**：
> - **首次启动较慢**：`AnyBox.exe` 内嵌了包含 pip 的完整 Python 3.12 沙盒环境，初次运行时需要解压沙盒并可能安装依赖，启动可能需要 **1-3 分钟**，请耐心等待。后续启动会快很多。
> - **请将 exe 放在单独文件夹中**：运行过程中会在 exe 所在目录生成 `sandbox/`（沙盒环境）、`tools/`（工具脚本）、`logs/`（日志文件）等文件夹。建议将 `AnyBox.exe` 放在一个专用的空文件夹中，避免与其他文件混淆。

### 2. 配置 API Key

首次启动会进入向导，指引你获取并填写 DeepSeek API Key。（可以填其它的，但建议是用deepseek，因为开发者只测试了deepseek的）

### 3. 开始使用

在主界面对话框中描述你的需求，例如：
- *"帮我写一个压缩当前目录下所有 PNG 图片的工具"*
- *"创建一个 CSV 文件合并工具，支持选择多个文件"*
- *"生成一个 Markdown 阅读器，带实时预览"*

## 📁 项目结构

```
LogicForge/
├── main.py                  # 应用入口，生命周期管理
├── AnyBox.spec              # PyInstaller 打包配置

│   ├── llm_controller.py    # LLM API 调用与工具代码生成

│   ├── wizard/              # 初始化向导（API 配置）
│   └── tool_executor/       # 动态 UI 构建与工具执行
├── utils/                   # 工具模块（日志等）
├── assets/                  # 图标资源
└── tests/                   # 测试脚本
```

# 安装依赖
